DESTINY INTERACTIVE — LIGHT THEME WEBSITE

Files:
- index.html (Home)
- about.html
- services.html
- games.html
- career.html
- contact.html
- styles.css
- script.js
- assets/original-image-sources.json (original image URLs catalogued from the current website)

HOW TO PREVIEW:
Open index.html in Chrome, or run a local server from this folder:
  python -m http.server 8000
Then visit http://localhost:8000

IMPORTANT IMAGE NOTE:
The image URLs in this build point to media hosted on the original destinyinteractive.com website. The image sources were identified from the public site, but the binary files could not be downloaded in this environment. Internet access is required for these images to load. If you want a fully offline package with the images physically copied into /assets, download the original WordPress uploads or provide a WordPress media export and the image references can be switched to local files.

CONTENT:
Company descriptions, leadership names, listed games, services, contact details and career roles are based on public pages of destinyinteractive.com. Verify current vacancies and business details before publishing.

Studio photos are crops from the supplied gallery screenshot (low resolution); replace assets/studio-photo-1.jpg through studio-photo-5.jpg with original full-resolution photos before launch.
